# Bank Customer Segmentation & Churn Analysis

## Project Overview

This project analyzes synthetic banking customer data to explore
customer segmentation, retention patterns and churn behaviour.

## Objectives

- Analyze customer demographics and account information.
- Measure customer churn and retention.
- Segment customers using K-Means clustering.
- Explore churn patterns across geography and age groups.
- Present findings through an interactive Streamlit dashboard.
- Demonstrate SQL analytical queries.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- SQL
- Streamlit
- Plotly
- Power BI (planned dashboard)

## Project Structure

- data: synthetic customer dataset
- notebooks: exploratory data analysis
- sql: analytical SQL queries
- src: data cleaning and segmentation
- app.py: interactive dashboard

## How to Run

Install dependencies:

pip install -r requirements.txt

Generate the dataset:

python generate_data.py

Run the dashboard:

streamlit run app.py

## Dataset

The dataset is synthetically generated for educational and portfolio
purposes. It does not represent actual bank customers.

## Disclaimer

All findings are based on synthetic data and should not be interpreted
as conclusions about a real financial institution.
